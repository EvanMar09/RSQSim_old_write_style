# Citation Instructions for RSQSim

If you use this software or any code within `RSQSim_src` for your research, please cite the following publications:

1. **Dieterich, 1995**  
   *Earthquake simulations with time-dependent nucleation and long-range interactions*  
   [Download PDF](https://npg.copernicus.org/articles/2/109/1995/npg-2-109-1995.pdf)

2. **Dieterich & Richards-Dinger, 2010**  
   *Earthquake Recurrence in Simulated Fault Systems*  
   [Springer Link](https://link.springer.com/article/10.1007/s00024-010-0094-0)

3. **Richards-Dinger & Dieterich, 2012**  
   *RSQSim Earthquake Simulator*  
   [GeoScienceWorld Link](https://pubs.geoscienceworld.org/ssa/srl/article/83/6/983/315277/RSQSim-Earthquake-Simulator?guestAccessKey=)

*Note: Keith Richards-Dinger and Jim Dieterich are the original authors of this software and granted permission to host this source code as an open-source project.*

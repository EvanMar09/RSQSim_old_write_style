# Citation Instructions for RSQSim

*Note: Keith Richards-Dinger and Jim Dieterich are the original authors of this software and granted permission to host this source code as an open-source project.*

If you use this software or any code within `RSQSim_src` for your research, please cite the following foundational publications:

1. **Dieterich, J. H. (1995).** Earthquake simulations with time-dependent nucleation and long-range interactions. *Nonlinear Processes in Geophysics*, 2(2), 109–120.  
   [Download PDF](https://npg.copernicus.org/articles/2/109/1995/npg-2-109-1995.pdf)

2. **Dieterich, J. H., & Richards-Dinger, K. B. (2010).** Earthquake Recurrence in Simulated Fault Systems. *Pure and Applied Geophysics*, 167, 1087–1104.  
   [Springer Link](https://link.springer.com/article/10.1007/s00024-010-0094-0)

3. **Richards-Dinger, K., & Dieterich, J. H. (2012).** RSQSim Earthquake Simulator. *Seismological Research Letters*, 83(6), 983.  
   [GeoScienceWorld Link](https://pubs.geoscienceworld.org/ssa/srl/article/83/6/983/315277/RSQSim-Earthquake-Simulator?guestAccessKey=)
